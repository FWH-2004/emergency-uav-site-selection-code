本仓库为本科毕业论文《应急条件下无人机配送站点布局优化研究》的配套程序代码。论文主要围绕灾害应急条件下无人机配送航空站的布局优化问题展开，重点研究传统圆形覆盖模式与椭圆覆盖模式在无人机应急配送网络中的适用性，并构建基于椭圆覆盖的 e-pCP 选址模型。为了提高模型求解效率，论文进一步采用 Benders 分解算法进行求解，并通过案例分析验证模型和算法的有效性。

1. 研究背景
灾害发生后，道路损毁、交通受阻和需求点分散等问题会影响应急物资配送效率。无人机具有机动灵活、受地面道路影响较小等特点，适合在灾害初期承担药品、食品和生活物资等小批量、高时效配送任务。传统圆形覆盖模型通常假设无人机从同一航空站起飞并返回原站，主要描述单站往返服务过程。本文引入椭圆覆盖思想，允许无人机从一个航空站起飞，服务需求点后降落至另一个航空站，以更好地刻画多航空站之间的异站起降和双站协同服务关系。

2. 代码用途
本仓库代码主要用于完成论文中的模型验证、案例分析和算法对比，具体包括：
1. 小规模算例下的椭圆覆盖模型可行性验证；
2. 案例一中圆形覆盖模型与椭圆覆盖模型的对比分析；
3. 单点失效情景下两类覆盖模式的鲁棒性分析；
4. 案例二中扩展数据的生成；
5. 基于 Gurobi 的 e-pCP 模型直接求解；
6. 基于 Benders 分解算法的 e-pCP 模型求解；
7. 不同开放航空站数量下的敏感性分析。

3. 文件说明
| 文件名 | 主要内容 |
| `01_model_validation.py` | 用于绘制小规模算例中的圆形覆盖与椭圆覆盖示意图，对模型基本逻辑进行可视化验证。 |
| `02_case1_circle_ellipse_comparison.py` | 用于案例一中圆形覆盖模型与椭圆覆盖模型的求解，并比较两类覆盖模式在正常状态和单点失效情景下的表现。 |
| `03_case2_expand_data.py` | 用于将原始点位数据扩展为 100 个点位，为案例二中的大规模求解实验提供数据。 |

4. 模型说明
本文构建的 e-pCP 模型以无人机异站起降和双站协同服务为基础。设每个需求点由两个开放航空站共同服务，需求点到两个开放航空站的距离之和表示该需求点的双站覆盖距离。模型目标是在给定开放航空站数量的条件下，最小化所有需求点中的最大双站覆盖距离和。
该模型可以用于分析应急条件下无人机航空站的空间布局效果，也可以用于判断在一定无人机续航能力下，当前航空站布局是否能够满足全网双站协同覆盖要求。
